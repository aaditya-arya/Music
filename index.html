Equipment & Asset Scope

Disciplines and asset classes audited by our certified field surveyors across fabrication shops and raw material mills.

1

Basic Material

Verification at steel mills, foundries, and stockyards covering plates, seamless and welded pipes, forged flanges, fittings, and castings.

Positive Material Identification (PMI via XRF/OES)
Tensile, Charpy V-notch impact, and Hardness test witness
Mill Test Certificate (MTC) verification & heat correlation
Standards: ASTM, ASME Sec II, EN 10204 Type 3.1 & 3.2
2

Fabricated Structures

Surveillance at structural yards and piping shops covering process piping spools, heavy steel structures, modular skids, and manifolds.

Fit-up inspection, root gap, and bevel angle checks
Weld visual audit, NDE witness, and PWHT chart review
Hydrostatic pressure testing and isometric drawing validation
Standards: ASME B31.3, ASME B31.1, AWS D1.1, EN 1090-2
3

Static Equipment

Critical path inspection for pressure vessels, shell & tube heat exchangers, storage tanks, columns, and industrial boilers.

Plate layout, shell rolling radius, and nozzle orientation audit
Reinforcement pad pneumatic leak test & radiographic film review
Tube-to-tubesheet joint expansion torque & hydro-test witness
Standards: ASME Sec VIII Div 1/2, TEMA, API 650, API 620, IBR
4

Rotary Machinery

Performance run auditing and factory acceptance testing for centrifugal pumps, gas compressors, industrial turbines, and gearboxes.

Rotor dynamic balancing witness (ISO 1940 Grade G2.5)
Mechanical Run Test (MRT) with vibration and temperature logging
Head, flow, and NPSH required (NPSHr) suppression curve audit
Standards: API 610, API 617, API 618, ISO 10816
